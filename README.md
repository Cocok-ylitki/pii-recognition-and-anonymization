# Распознавание и синонимическое обезличивание персональных данных

Курсовая работа, вариант 13. 

Имена и фамилии распознаёт модель RuBERT. Для остальных атрибутов программа использует регулярные выражения и проверяет контрольные цифры, где они предусмотрены.

## Запуск

Понадобятся Python и Git LFS. Готовые веса модели и тестовая выборка включены в репозиторий.

```bash
git clone https://github.com/Cocok-ylitki/pii-recognition-and-anonymization.git
cd pii-recognition-and-anonymization
git lfs pull
python -m pip install -r requirements.txt
python main.py --file demo.txt
```

Программа выводит JSON со списком найденных атрибутов в формате `[тип, начало, конец]`. Позиции считаются с нуля, конечная позиция в найденный фрагмент не входит.

## Проверка качества

```bash
python evaluate.py
```

Оценка проведена на 692 текстах. Скрипт выводит точность, полноту и F1 по каждому атрибуту, а также средние метрики по всей программе. Макро-F1 по BIO составила **0,9819**, взвешенная F1 - **0,9727**.
